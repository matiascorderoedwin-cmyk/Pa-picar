# Pa Picar — Sistema de facturación

Aplicación para la facturación y gestión de inventario de Pa Picar, desarrollada en Python, Flask y PostgreSQL.

## Estado del proyecto

La versión más reciente corresponde a la Etapa 5: autenticación con perfiles de administrador y vendedor, facturación, administración, inventario, reportes y diseño visual oficial.

Este repositorio está destinado a almacenar el código y los recursos visuales; las credenciales de la base de datos y los archivos `.env` deben mantenerse fuera de GitHub.

## Seguridad

El servidor de desarrollo de Flask no debe exponerse directamente a Internet. Supabase y Vercel todavía no están configurados.

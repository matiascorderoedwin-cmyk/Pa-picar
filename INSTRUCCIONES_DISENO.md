# Pa Picar · Etapa 5 · Identidad visual

Este paquete conserva el app.py de Etapa 5 y sus plantillas; solo personaliza el diseño.

1. Detén Flask (Ctrl+C) y haz una copia de seguridad del proyecto.
2. Copia app.py y la carpeta templates del ZIP a tu proyecto, reemplazando los archivos equivalentes.
3. Copia LOS DOS archivos de la carpeta static del ZIP dentro de la carpeta static de tu proyecto. NO borres otros archivos de static (especialmente estilos.css).
4. Conserva .env, .venv y PostgreSQL sin cambios. NO ejecutes migraciones adicionales.
5. Ejecuta python app.py y abre http://127.0.0.1:5000.
6. Si no ves los colores nuevos, actualiza con Ctrl+F5.

El logo incluido se recortó de la imagen original aportada por el negocio, sin redibujarlo. No se ha alterado la lógica de facturación ni los permisos.

Importante: este paso NO publica el sistema en Internet. La configuración de despliegue HTTPS se realizará después de probar los cambios.
